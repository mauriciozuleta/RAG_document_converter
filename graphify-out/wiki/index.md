### Extraction behavior

All PDFs now use page-aware extraction. `document_extract.py` preserves raw text, source-line bounding boxes, page sizes, a spatial text view, and source page numbers. Reading order remains a pdfminer heuristic; the original coordinates are retained for verification. Repeated values, captions, identifiers, headers, and footnotes are not deleted. Vertical text and text inside PDF figures are included in layout analysis.

HTS detection adds chapter context and supplementary physical table rows. Its authoritative content is now the spatial view, preserving indentation and superscripts. The supplementary `table_rows` are explicitly not normalized tariff records; wrapped cells and inherited values require review. The previous flattened labeled-row rendering is no longer the primary output.

Schema version 2 keeps `title` and `sections`, adds `source_lines`, `raw_text`, `layout_text`, `warnings`, and `review_required`. Markdown uses variable-length fenced text blocks to preserve layout and safely display literal Markdown from source documents. Per-page warnings appear in both Markdown and JSON and in conversion logs. General document-type selections are recorded as metadata rather than forcing destructive heading heuristics.

Empty/sparse text, unresolved glyphs, embedded images, and graphical rules are flagged. No OCR engine is installed or invoked: scans and text inside images need OCR before results can be considered complete. This pipeline is a conservative local preservation format, not a guarantee of semantic reconstruction for arbitrary tables, mathematics, or diagrams.
